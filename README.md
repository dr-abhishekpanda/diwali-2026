# Happy AI-luminated Diwali: The Diya Network

A Diwali lesson in how AI learns. Every diya on the page is an artificial neuron. Together, 361 parameters learn to draw a diya from 1,600 labelled dots, live in the browser.

**Live page:** https://dr-abhishekpanda.github.io/diwali-2026/

## Files

- `index.html`: the whole page in one file, with no build step and no server. It holds a one-neuron playground, a forward pass, live training at three learning rates, test dots, the step up to large language models, a glossary and a WhatsApp share button.
- `ai-luminated-diwali-2026.mp4`: the 88-second vertical film.
- `ai-luminated-diwali-status-1080x1920.jpg` and `ai-luminated-diwali-card-1080x1720.jpg`: images for WhatsApp.
- `og-ai-luminated-diwali.jpg`: the image shown when the link is shared.

## Publishing

In the repository's Settings, open Pages and deploy from the `main` branch, root folder.
